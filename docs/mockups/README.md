# Mockups

Early mockups from the 2026-10-16 design session, GGX dark theme. They are fragments made for the
visual companion, so open them through its frame, or treat them as reference for structure
and colours.

- `landing-and-result-options.html`: all options shown (landing A/B, result A/B/C).

## Chosen by the owner

- **Landing A**: centered and calm. Headline "Drop a trace to see what your agent really did.",
  one drop/paste target, buttons "Try a sample" and "Find my sessions", and the line "Runs
  entirely in your browser. Nothing is uploaded."
- **Result C**: canvas-first. Graph is the main canvas with pan/zoom; findings and inspector
  are floating panels; a timeline strip runs along the bottom; the waterfall is a view
  switch. Failing nodes are marked; the first error is framed on load.

Rejected for now: landing B (ghosted preview), result A (three fixed panes), result B
(single-column story). Ideas worth borrowing later: the "This run failed at X" verdict line
from result B as a headline in the Overview.
